## 2026-10-30 本对话规则归档

- **共享组件**：页头图标+文字动作使用 `createPageHeaderAction()`；所有搜索字段使用 `createSearchField()`，放大镜默认 Secondary；全站时间使用 `foundations/time.js`，7 天内相对显示，7 天后显示本地绝对时间。
