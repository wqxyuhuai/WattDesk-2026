## 玻璃与 hover 高光

以下为当前有效方向；早期较弱的白边、浅色中间值以及界面中的材质对比开关均已被后续反馈替换，不再恢复。

- 正式方向只用 `figma` 双层玻璃：Fill + Shadow 底层与 Glass Effect 高光层；暗色外轮廓和窄白色内亮边分开绘制。光学参数集中在 `glass-material.css`，组件只提供尺寸与圆角，不能各写一套。
- 深色已确认，不因调整浅色而回退。浅色使用独立主题参数：压灰的中性底、细白亮边、柔和悬浮投影和短接触阴影；修改浅色不得改变深色。
- hover 与键盘 focus 都增强表面和底缘亮度，并在指针附近显示克制的跟随光晕；离开后淡出。不整圈发白、不倾斜、不移动、不改变尺寸，也不重做材质。
- 局部指针弧与整圈基准分开：深色普通表面白色 `.72`、圆钮/面板 `.62`，宽度 `1px`、`inset:0`；浅色普通表面近黑 `.42`、圆钮 `.72`、面板 `.46`，宽度 `0.5px`、`inset:-0.5px`。整圈基准为浅色普通玻璃上下 `.09`、左右 `.38`（纵向渐变），hover `.11/.42`；浮层为 `.16/.20`（外圈 / 侧缘），全屏搜索结果面板使用搜索专用 `.08/.10`。浅色反射层另有白色 `.62`，不是局部弧，不能与 `.42` 互换。浅色轮廓必须贴齐宿主真实外轮廓，不能留下亮缝，也不能向内挤占表面；圆钮内部光斑 `.40`，普通表面与面板分别为 `.58` / `.80`。
- 正圆玻璃控件由共享材质自动识别并加 `.wd-glass--disc`：正方形且半径达到短边一半即可，使用更窄的边缘高光和短半径光晕；调用方不手写该类，也不改半径或布局。
- 触屏和减少动态效果关闭光照跟随；禁用控件不响应。未选中 tab 保留正常材质，不能看起来像 disabled。
- `2026-10-21` Glass Surface 是网站所有浮窗的默认材质：工作区标签 tooltip、图表 `Chart options`、顶栏 `Language` / `WattDesk` / `Appearance` 菜单、toast，以及图表数据浮签（如 `08 Oct, 12:00-13:00 / Energy generated`）都必须复用它；后续新增浮窗同样默认套用，不另写模糊、底色或投影。
- `2026-10-21` 浮层玻璃不能读成实心：深浅主题都要能辨出背后页面，浅色尤其不能靠加不透明度换干净。所有可交互浮层和只读浮签共享同一材质分支；tooltip、toast、数据浮签不响应缩放，只保留材质与指针光晕。
- `2026-10-21` 浅色玻璃不要显眼的黑细线；`2026-10-22` 最终校准为普通玻璃上下 `.09`、左右 `.38`、hover `.11/.42`，浮层保持 `.16/.20`，全屏搜索结果面板按搜索专用 `.08/.10`；深色已确认，不为本次调整改动。
- `2026-10-22` 浅色玻璃描边最终校准：要能看出玻璃的上下厚度和纵向渐变。上下保留细黑灰线，左右比上下更深但不读成黑框；线宽按真实浏览器逐档调到用户认可的细度。侧边浓度经过“近黑 → 过淡 → 中间值”两轮修正，最终为上下 `.09`、左右 `.38`，hover 仅小幅增强。描边不能整体变成均匀灰色。
- `2026-10-22` 浅色玻璃底部厚度保持 `14px`，过渡要自然，不能有一段明显纯白的大面积台面；保留上下白色厚度感，但纯白占比要低，底缘从玻璃底色连续缓入。深色不变。
- `2026-10-22` 浅色全屏搜索要保留背景可辨：遮罩用 `10%` 黑底与 `16px` 模糊，不能沿用深色的 `29% + 28px` 密集遮罩；结果卡片使用轻投影与外沿（`.055 / 16px / 34px`、`.08/.10` 外沿、`.02` 接触阴影），不能出现黑色重底。该规则只覆盖浅色全屏搜索，深色与其他玻璃浮层保持原参数。

## 动效与投影

- 动效必须是组件级共享契约：`shared.css` 自动加载 `foundations/motion.css`；新页面、新组件和动态 DOM 自动继承，禁止逐页补 `transition` 时长或缓动。组件只声明默认与激活视觉值，唯一已记录的单向例外可以覆盖单项属性。
- `2026-10-21` hover 颜色节奏改为“弹性灵动”并整体拉长：进入 `240ms`（`cubic-bezier(.16,1,.3,1)`，快起缓收），离开 `360ms`（`cubic-bezier(.3,0,.2,1)`，柔和退场）；侧栏 `Cell balance`、`Module balance`、`Device track`、`Add tab` 等按钮和 tab 统一放缓，用户要求“丝滑一点”。宿主 hover / 键盘 focus 时切换共享变量，背景、文字与图标叶节点继承同一节奏，不再统一为单一 `260ms`。本轮只改颜色/背景/下划线/微光；玻璃缩放仍为 hover `300ms`、按下 `110ms`、回落 `420ms`。
- 一般 hover 只改变颜色、背景、下划线和光晕，控件与文字不位移、不缩放、不旋转、不改尺寸。首页专用：唯一位移例外是首页前两张可点击状态卡内部箭头向右上移动 `2px`，卡片本体不动。
- 点击展开/收起允许高度、透明度或轻微浮层缩放，须可中断、可反向，不能等动画结束才响应。折叠使用原稿实心箭头平滑旋转 `90°`，不能通过换图假装旋转。`2026-10-20`：侧栏 `Teams` 默认收起，`Device tool` 保持默认展开；`Teams` 首次点击展开，之后可正常收起。
- 玻璃是全站唯一允许按压缩放的体系，由共享材质自动继承：普通宿主 hover `1.025` / 按下 `1.065`，正圆宿主 hover `1.07` / 按下 `1.18`。按下 `110ms` 快速起步，松开 `420ms` 缓慢回落，并带极小的非等比液态拉伸；按下差必须肉眼可辨，36px 圆钮快速点击也不能只闪一下。
- 缩放原点必须是组件自身物理中心，不能是左上方或页面节点原点；只改变视觉矩阵，`offsetWidth` / `offsetHeight`、布局槽位和命中区不变。减少动态效果与粗指针设备直接复位。
- 复合容器不整体缩放：顶部 `.wd-glass-chrome` 整组、`.wd-glass--surface` 弹窗/浮层保持静止，只有内部独立玻璃控件响应。日期/时间弹窗里点击日期框或 Apply，只让对应控件反馈；该语义在共享层实现，不逐页补禁用规则。
- `2026-10-20` 纯展示玻璃卡不缩放：`Connected devices` 与 `Self-consumption` 没有点击目标，不得因 hover 或按下放大；材质和指针光晕保留。`Sites online` 与 `Needs attention` 可点击，继续保留 hover / 按下缩放。该区分由共享材质 `interactive:false` 实现，不在页面或单卡补 `transform` 例外。
- 刷新只让图标转一圈并防重复触发，容器不旋转。图表首次可见轻量载入，标题、数值和坐标轴保持稳定，不循环、不伪装实时数据。
- 搜索与状态卡阴影不被裁切。页面底部留白由单独的布局文档负责，本规范只约束组件和动效，不在规则文件中改该几何值。

- 2026-10-20：载入效果只放在右侧大卡片内部，左侧边栏不做 Loading；工具站优先效率，真实等待超过 `140ms` 才显示骨架，快速加载绝不闪骨架。骨架必须像组件共享能力一样统一挂载，避免逐卡补动画或漏加；单次柔光扫过、内容随后淡入，不循环，不伪造进度。该要求适用于首页状态卡与图表卡的真实载入，不扩展为全屏 Loading。
