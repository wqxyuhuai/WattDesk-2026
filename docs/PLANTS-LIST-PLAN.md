# 电站列表（Plants）改版方案 — 需求整理与设计思路

更新：2026-10-26 · 状态：**P0 已实现；列表/详情 URL 已实机验证，完整视觉矩阵待跑**（见第 13 节）；P1 / P2 仍为方案 · 依据：`AGENTS.md` / `DESIGN-SYSTEM.md` / `docs/PROJECT-STATUS.md`

## 0. 一句话结论

现在的白色页面是**现网 UI + 手写功能批注**，它给出的是“功能真源”，不是视觉稿；新版要做的是把这些能力重新收进新版深色玻璃体系里的一页工作台：**占满右栏的自适应表格 + 顶部筛选与搜索**，用 Linear 的行密度与列菜单解决“功能一轮轮加上去后表头越来越挤”的问题，整行点击直接进电站详情，不再叠加多选与行内操作。

## 5. 详细设计

### 5.1 页头

- 左侧：`Plants`（页面级标题，34px / 590 / 41px 行高，沿用首页大标题规则）、右侧次级文字 `128 plants`；筛选生效时改为 `24 of 128 plants`，不使用独立大数字卡片。
- 右侧：唯一主按钮 `添加电站`（共享 `.wd-button--primary`）。旁边允许一个中性按钮 `导入`（画板未出现，列为待确认）。
- 页头高度固定 88px，标题不随滚动消失（表格内部滚动，页头不动）。

### 5.2 工具栏

- 搜索：共享 `createSearchField()` 的 46px 胶囊，默认宽 320px、可增长到 420px；占位文案复用共享常量（`Search plants, installers or SN` 一类的单一来源，不写两份）。`/` 与 `Ctrl K` 都聚焦到此。
- 公司范围：带公司图标的下拉触发器，文案随选择变化（`All companies` → `3 companies`）。
- 快捷筛 `Offline` / `Attention`：带图标的开关按钮，按下即开、再按即关，落在与 B5 chip 同一份状态上，不允许出现“按钮显示开、chip 显示关”。
- `筛选 (n)`：打开右侧锚定的筛选面板（不是左侧抽屉），内含连接状态、运行状态、电站类型、设备、固件、更新时间；长列表带搜索框与 `Online (12)` 计数。
- `列`：列显示设置（P1）。
- 右侧留一个分隔后的图标组：`刷新`。工具栏不放入无实际功能的三点菜单。

### 5.3 筛选控件的统一状态模型（对应批注「所有按钮规则统一 见顶部」）

所有顶部筛选控件是**同一个组件**的实例，只有 4 个状态，不允许各写一套：

| 状态 | 触发 | 视觉 |
|---|---|---|
| Default | 无值 | 文字与图标 `Labels/Secondary`；中性玻璃 |
| Hover / focus-visible | 指针或键盘 | 文字与图标同变 `Labels/Primary`，玻璃边缘微亮（不做位移/放大文字） |
| Open | 点开浮层 | 保持 Primary，chevron 平滑转 180°，控件背景进入选中态，直到浮层关闭 |
| Applied | 有生效值 | 文字为已选值（`Offline` 而不是 `All`）、Primary；是否需要额外描边由具体控件决定，不叠加第二套高亮 |

行为约定：点控件开、点外部关、`Esc` 关、点另一个筛选控件时前一个关；浮层跟随触发元素滚动（共享 `registerPanel()`）；筛选项改动即时生效（不需要 Apply），与日期选择器“草稿 + Apply”的语义不同，须在面板里写清。

### 5.4 表格

**默认列（P0）**

| 列 | 内容 | 宽度 | 对齐 | 排序 | 筛选 | 说明 |
|---|---|---|---|---|---|---|
| ☆ | 书签 | 40 | 中 | — | — | 行 hover 才显示 |
| 电站 | 电站名 | `flex:1`（min 220） | 左 | ✓ | 文本/搜索 | 主文字 14/510；未分配显示占位 |
| COM. | 连接状态 | 96 | 左 | ✓（严重度） | ✓ | 图标 + 文案，不只是图标 |
| SN | 设备序列号 | 190 | 左 | ✓（文本） | ✓ | 等宽数字、截断 + 悬停全文 + 复制 |
| 类型 | Heating / Battery / Hybrid | 130 | 左 | ✓ | ✓ | |
| Power | 功率 kW | 96 | **右** | ✓（数值） | — | 有符号；`--` 表示无数据 |
| 状态 | Running status | 136 | 左 | ✓（严重度） | ✓ | 图标 + 文案 |
| 固件 | Firmware version | 116 | 左 | ✓（版本号） | ✓ | 等宽数字 |
| 更新 | Last update | 136 | 左 | ✓（时间） | ✓（时段） | 相对时间 + 悬停绝对时间 |

**可选列（P1，默认隐藏）**：公司 / 安装商、设备（BMS & Battery / Heater / Hybrid Inverter）、地址、组织。

**行与表头**

- 表头 40px，文字 `Caption1/Emphasized`（12/590），`Labels/Tertiary`；列右缘出现 chevron（hover / focus 时显示，键盘聚焦表头也显示）。
- 行高默认 **48px**（紧凑 40 / 宽松 56，P2 作为显示选项）。行高变化不改变字号。
- 单元格左右内距 12px，首列 16px；数字列右对齐并使用 `font-variant-numeric: tabular-nums`。
- 行分隔线 1px `--wd-separator-nonopaque`；最后一行下不画线。
- hover：整行填充（浅一档的中性填充），书签淡入（240ms 颜色过渡，不做位移/缩放）；整行是唯一点击目标，hover 就是“可进入详情”的唯一信号；行内文字不整体变色。
- 键盘焦点：行内 2px `Accents/Blue` 内描边（`offset:-2px`），与 hover 可同时存在但不叠加两种亮度。
- 表头在表体内部滚动时粘性；按满宽自适应时不出现横向滚动，只有收窄到极限才允许表体自身横向滚动。

**容器**：表格放在页级主面板上（沿用右侧大底板的 10px 圆角与浅色短投影），**不使用玻璃**——材质只留给浮层与工具栏控件。

### 5.5 排序

- 单列排序（多列排序 P2）。点击表头或表头菜单：无 → 降 → 升 → 无（或按列类型给合理默认）。
- 排序比较规则必须按类型分开，不能统一当字符串：
  - 名称：`Intl.Collator`，数字按数值（`Plant 2` 在 `Plant 10` 之前）。
  - 功率：数值；`--` 恒排最后（正序倒序都在最后）。
  - 版本号：按 `.` 分段数值比较（`V450.105` > `V440.104`，不能按字典序）。
  - 时间：按时间戳；相对时间只影响显示。
  - 状态：按严重度 `Attention > Offline/Unbound > Normal` 的业务顺序，不按字母。
- 默认排序待定（建议 `Last update` 倒序，见 11.3）。

### 5.6 列菜单与显示选项

- 表头 chevron → 浮层（Glass Surface，18px 圆角，240px）：`升序 / 降序`（当前排序列显示勾选）、`筛选此列…`（跳/聚焦到筛选面板对应分组）、`隐藏此列`、分隔线、`列设置…`。
- `列` 按钮 → 显示选项面板（P1）：列开关列表 + 恢复默认；顺序调整放 P2。
- 读法二义：画板第 3 张的 `隐藏` 批注也可能是“把浮层隐藏起来”的制图备注，而不是“隐藏列”功能。见 11.1。

### 5.7 公司范围与层级（替换画板里压在表格上的浮动树）

画板里的作法是点击行首图标，在表格左侧浮出一棵公司树，覆盖住列内容。建议改为：

1. 公司下拉（B2）内是**树形多选**：每行 checkbox 三态（未全选 / 已全选 / 已部分选择），支持搜索公司名、展开/收起、显示每个节点下的电站数。
2. 选中后工具栏文案变为 `2 companies`，C 区出现 chips，表格按公司过滤。
3. 需要“按公司分组浏览”时，用表格分组行（P2，`Group by: 公司`），而不是常驻的浮动树。
4. 树内 checkbox 三态必须真实反映子节点状态，不能用“全选/全不选”近似。

理由：树压住表格会遮住 SN、类型等列；多选与筛选分成两套状态后极易不同步。

### 5.8 书签（关注）

- 三态：默认（未关注、无 hover）→ 不显示；行 hover / 键盘聚焦行 → 空心书签淡入；已关注 → 实心常显（任何状态）。
- hover 到图标本身 → 空心转实心的预览态（不写数据），离开回退；点击 → 实心 + 轻量 toast（`已关注`，可撤销）。
- 点书签**不触发行打开**（阻止冒泡）。
- 数据落本地 `localStorage`（如 `wattdesk.plants.following.v1`），与首页 `Following` 是同一份关注列表；首页 Following 目前是静态示例，接入列为 P2，不宣称已打通。

### 5.9 行点击与详情导航

- 整行是唯一主操作：点击任意非交互区域进入电站详情；行聚焦时 `Enter` 等价。**不做复选框、不做行尾 `⋯` 菜单、不做行内按钮组**（按 2026-10-26 确认）。
- 行内唯一允许“不触发跳转”的交互是**书签**：点击必须 `stopPropagation` / `preventDefault`，只改关注状态。
- SN 全文、时间全文一律用悬停 tooltip，不做复制按钮，避免与整行点击抢目标。
- 未分配设备行没有电站身份，不能进入详情（见 5.10）。
- 详情页是**独立依赖**：本期只保证行可点击、可键盘进入，详情页落地前用共享 Coming soon 承接（带电站名），不伪造详情内容；URL、标签标题、面包屑、刷新还原等随详情页一起决策（见 8.6）。

### 5.10 未分配设备与「自动新建电站」（241209）

- 未绑定设备作为**行**出现在同一张表里（不另开 tab），电站名位置显示虚线占位 `未分配设备` + `?` 图标。
- 悬停 `?` 显示提示：`This device is not currently associated with any plant. Please proceed with the setup.`（英文原文保留，是否本地化见 11.7）。
- 按最新确认**不放行内按钮**：自动新建由系统流程完成（名称、公司、地址按设备与安装信息预填），完成后该行转为正常电站行即可点进详情；创建完成前显示 `?` 占位，行不进入详情。

### 5.11 状态体系（D5 / D6）

| 维度 | 取值 | 图标 | 建议颜色 | 说明 |
|---|---|---|---|---|
| 连接 | Online | 信号柱满格 | `Accents/Green` | 明确在线 |
| 连接 | Partially offline | 信号柱 + 警示 | `Accents/Orange` | 部分设备离线 |
| 连接 | Offline | 信号柱 + 断点 | `Accents/Red` | 全部离线 |
| 连接 | Unbound device | 斜杠圆 | `Labels/Tertiary` | 未接入，不是故障 |
| 运行 | Normal | 圆勾 | `Accents/Green` | |
| 运行 | Attention | 感叹 | `Accents/Orange`（画板为红，待校对） | 需处理 |
| 运行 | Unbound | 斜杠圆 | `Labels/Tertiary` | 与连接维度的未绑定同源 |

- 两个维度语义不同，不能合并成一列；列标题明确写 `Connection` / `Running status`，避免画板里 `COM.` 这种只有图标可读的缩写。
- 颜色不写死 hex，全部走 `Accents/*`；`Attention` 用橙还是红需与首页 `Needs attention` 卡一致（11.3）。
- 批注「在线以及正常状态的图标制作动态」：建议**不做常驻循环动画**。列表 100+ 行同时呼吸会变成噪音，也违反现有“不循环、不伪装实时”的动效边界。方案：数据到达/刷新时播放一次（信号柱自下而上 3 段各 35ms 错峰、勾号描边一次），减少动态效果时直接静态。若确实需要常驻呼吸，只给“当前可见且状态为 Online/Normal”的少量行以极低幅度（≤4%）透明度呼吸，需你确认。

### 5.12 数据展示规则

- **功率**：`Power (kW)`，单位进表头，单元格只放数字；充放电带符号（充电 `+`、放电 `−`），加热器不带符号——由数据字段 `powerSigned` 决定，不在渲染层按设备类型猜。无数据 `--`（不用 `0`）。
- **时间**：24h 内相对时间（`15 mins ago`），更早显示 `YYYY/MM/DD HH:mm`；悬停显示完整时间 + 时区（沿用首页 `As of` 已删除的前提下，这里用 tooltip，不新增页面级时间脚注）。
- **SN**：等宽数字、中段截断（`WSAUTSM382…XXXXXX`）、悬停显示全文；**不提供复制按钮**，避免与整行点击抢目标。
- **空值**：统一 `--`，不用空白或 `N/A` 混用。
- **数字对齐**：功率、固件、SN 全部 `tabular-nums`，避免滚动时列宽跳动。

### 5.13 滚动与返回顶部

- 页头与工具栏固定，**只有表格区域滚动**（表格内部滚动 + 粘性表头）。与首页“整页滚动”不同，这是工作台类页面的合理差异，需要在 `docs/PAGE-LAYOUT.md`（尚未创建）里定下来。
- 返回顶部：右下角 36px 圆钮，表格滚动超过一屏才淡入；点击平滑回到顶部，减少动态效果时直接跳转。默认/悬停/点击沿用共享圆钮玻璃与按压矩阵。

### 5.14 加载 / 空态 / 错误

| 场景 | 表现 |
|---|---|
| 首次载入 | 表头立刻可用（静态），行区域显示骨架行（复用 `data-skeleton="text"`，或新增 `row` 变体）；140ms 内就绪不闪骨架 |
| 无任何电站 | 空态：`还没有电站` + 主按钮 `添加电站`（不是 Coming soon） |
| 筛选无结果 | `没有符合条件的电站` + `清除筛选`（次级按钮），并保留搜索框内容 |
| 请求失败 | 表格区域错误行 + `重试`（中性按钮）；工具栏保持可用，不清空已选条件 |
| 无权限 | 明确文案 + 联系管理员入口；不显示空表 |

### 5.15 键盘与无障碍

- `/` 或 `Ctrl/⌘ K` 聚焦搜索；`↑ ↓` 在行间移动焦点；`Enter` 进入详情；`Esc` 关闭浮层（再按一次把焦点还给搜索框）。
- 使用原生 `table` 语义（或 `role="grid"` 并完整实现 row/column 导航），表头 `aria-sort`，结果数通过 `aria-live="polite"` 播报；行不使用 `aria-selected`（不存在多选）。
- 列菜单、筛选面板：`aria-expanded` + `aria-controls`，`Esc` 关闭并把焦点还给触发元素。
- 所有状态图标必须有可读文本或 `aria-label`，不能只靠颜色区分（Connectivity 与 Running status 同色系时尤其重要）。
- 触控：行高与命中区在粗指针下放大到 ≥44px；书签在触控下常显。

## 12. 风险与防回归

- **两套筛选入口打架**：顶部筛选面板、快捷筛、列菜单都会改同一份状态，必须单一状态源（页面维护一份 `filters` 对象，三处只读/只能通过同一 action 修改）。
- **表格组件污染共享层**：`data-table` 只提供结构与状态，不接管页面业务；列定义由页面传入，不写死电站字段。
- **粘性表头 + 玻璃浮层的层级**：浮层必须高于表头，且滚动时不跟丢（共享 `registerPanel()` 已经处理，不要另写滚动监听）。
- **行内交互吞掉整行点击**：书签是唯一允许拦截点击的元素；tooltip、复制一律不加按钮，否则“点哪里都能进详情”会变成“点哪里都不进”。
- **行 hover 常显图标导致布局跳动**：书签槽位始终占位，只做透明度切换。
- **动画越界**：不新增位移 / 缩放（玻璃按压除外），不写局部 `transition` 时长，不循环播放。
- **示例数据被当成真实统计**：数量、SN、固件、更新时间全部标注演示，页面文案不写“实时”。
- **文档不同步**：组件落地时同步 `COMPONENTS.md`、`DESIGN-SYSTEM.md`、`PROJECT-STATUS.md`；本文只作为方案，不代表已实现。
